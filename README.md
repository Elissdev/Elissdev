## O que eu faço

- **Atendimento N1:** triagem, diagnóstico inicial e classificação por impacto e urgência.
- **Investigação:** leitura de log de aplicação e de pipeline, consulta SQL, análise de requisição HTTP e teste de API com Bruno e curl.
- **Escalonamento:** envio do caso para N2 ou desenvolvimento com passos de reprodução, evidência, hipótese e o que já foi descartado.
- **Documentação:** POP, runbook, fluxograma e artigo de base de conhecimento para reduzir chamado repetido.
- **Monitoramento:** acompanhamento de alertas e indicadores para identificar comportamento anormal antes do impacto ao cliente.
- **Qualidade:** casos de teste, regressão, automação E2E e de API, com defeito registrado e acompanhado até a validação.

## Como conduzo um chamado

```text
1. Registro     quem, o quê, desde quando, qual o impacto
2. Reprodução   passo a passo, ambiente, massa de dados
3. Evidência    log, status code, payload, consulta SQL
4. Isolamento   aplicação, dados, integração ou infraestrutura
5. Ação         resolução no próprio nível ou escalonamento com contexto
6. Fechamento   validação da correção e atualização da base de conhecimento
```
